# START_REFACTORY_V2

Prompt de execução para iniciar o `REFACTORY_V2` em uma nova sessão do Devin.

## Prompt

Execute a tarefa definida em `docs/REFACTORY_V2.md`.

Antes de qualquer implementação:

1. leia `docs/REFACTORY_V2.md` integralmente — ele contém tanto a especificação normativa (O QUE implementar) quanto a disciplina de execução (COMO executar);
2. estude o código real antes de assumir qualquer comportamento — classifique cada requisito como `CONFIRMED_IN_CODE`, `DOCUMENTED_ONLY`, `AMBIGUOUS`, etc.;
3. construa a matriz AS-IS → TO-BE para cada domínio crítico antes de alterar código;
4. execute o trabalho por fases, mantendo diagnóstico, evidências, invariantes, testes e compliance matrix conforme definido na seção "Disciplina de execução" do próprio `REFACTORY_V2`.

Não tente reconstruir os requisitos a partir deste prompt.

A fonte única de instruções é `docs/REFACTORY_V2.md`.

Não declare a tarefa concluída sem cumprir os critérios de conclusão definidos no próprio `REFACTORY_V2`.

Comece pela leitura integral do documento e pelo diagnóstico exigido. Depois prossiga com a execução conforme o protocolo, sem pedir confirmação para etapas que já estejam claramente definidas no escopo.
